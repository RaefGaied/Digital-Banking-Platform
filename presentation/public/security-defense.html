02 / CONTRÔLES EN PLACE

Des protections complémentaires.

Chaque mécanisme répond à un risque différent dans le périmètre actuel du projet.

01 IDENTITÉ

Authentification JWT

Le filtre lit le jeton Bearer, vérifie sa signature et son expiration, puis établit l’identité dans Spring Security.

API sans session serveur · jetons configurables
02 MOTS DE PASSE

Hachage BCrypt

Les mots de passe sont traités avec BCrypt, configuré avec un facteur de coût égal à 12.

Comparaison par encodeur · pas de stockage en clair
03 AUTORISATION

Accès par rôles

Les routes d’administration exigent le rôle ADMIN. Les API métier déclarées dans la configuration nécessitent une authentification.

Règles centralisées dans Spring Security
04 ABUS DE REQUÊTES

Limitation de débit

Un bucket par adresse IP autorise jusqu’à 1 000 requêtes par minute ; au-delà, l’API répond avec le statut HTTP 429.

Bucket4j · état en mémoire de l’instance
05 ORIGINE WEB

Politique CORS

Le backend autorise explicitement l’origine de développement http://localhost:5173 et les méthodes API déclarées.

Configuration à adapter en déploiement
+
PRINCIPE

Défense en profondeur

Un jeton valide ne suffit pas à obtenir tous les droits : la route applique aussi ses règles d’accès.

03 / REGARD CRITIQUE

Un projet académique, pas une banque en production.

Présenter les limites montre une compréhension réaliste de la sécurité et ouvre sur des évolutions concrètes.

01

Secrets et durée des jetons

La clé JWT et les durées sont configurées par propriétés : protéger les secrets et les faire tourner en environnement réel.

À RENFORCER
02

Limitation distribuée

Les compteurs sont en mémoire locale : avec plusieurs instances, prévoir un stockage partagé et une politique distribuée.

ÉVOLUTION
03

Confiance dans l’adresse IP

Le filtre lit X-Forwarded-For lorsqu’il est présent : en production, seul un proxy de confiance doit pouvoir le définir.

À VÉRIFIER
04

Configuration de déploiement

Restreindre CORS aux domaines réels, imposer HTTPS et compléter les contrôles par des tests et de la surveillance.
